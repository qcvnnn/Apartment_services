# ДЗ: Функции и 3D-модель

**Тема:** Удаленное заселение в апарт-отель

## Часть 1. Функции
Реализованы на странице деталей апартамента:

- `maxFreeDays` — максимум свободных дней подряд (цикл с постусловием)
- `getMissingServices` (diff) — какие услуги отсутствуют (работа с массивами)
- `mergeObjects` (merge) — объединение тарифов (работа с объектами)
