# ЛР1: Калькулятор (вёрстка)

**Тема:** Удаленное заселение в апарт-отель

## Задание
Создать калькулятор: вёрстка на HTML, CSS. Скопировать 3-5 основных цветов с выбранного сайта (хедер, фон, карточки, кнопки, hover) и 2-3 свойства (padding и т.д.)

## Как запустить
Открыть `index.html` в браузере.

## Пример цветов
- Золото: #B49450
- Фон: #FDF8F0
- Хедер: #ece8dd
