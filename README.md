# ЛР5: Фронтенд + AJAX (XMLHttpRequest)

**Тема:** Удаленное заселение в апарт-отель

## Задание
Заменить мок-данные на запросы к API через XMLHttpRequest.

## Реализовано
- Загрузка карточек с сервера (`ajax.get`)
- Добавление карточки (`ajax.post`)
- Редактирование карточки (`ajax.patch`)
- Удаление карточки (`ajax.delete`)
- Поиск и фильтр — локально (без дополнительных fetch-запросов)
