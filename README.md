# ЛР4: Бэкенд на Express (REST API)

**Тема:** Удаленное заселение в апарт-отель

## Задание
Разработать REST API для управления карточками апартаментов.

## Методы API
| Метод | URL | Описание |
|-------|-----|----------|
| GET | `/apartments` | Получить все карточки (с фильтром по `title`) |
| GET | `/apartments/:id` | Получить одну карточку |
| POST | `/apartments` | Создать новую карточку |
| PATCH | `/apartments/:id` | Обновить карточку |
| DELETE | `/apartments/:id` | Удалить карточку |
